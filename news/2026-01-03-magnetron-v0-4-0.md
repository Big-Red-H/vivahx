The major feature in this release is the addition of a REST API for getting registered server information. The REST API supports TLS and authentication through a bearer token. As the same with the rest of the application, it is controlled through a set of configuration files. The REST API is disabled by default. 

Additional changes include library upgrades to address security issues as well as bump up to Go 1.25.5. 

Thank you for your support of this project.
