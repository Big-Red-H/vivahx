Good day!

It's Fall, and looking at this project's history, that apparently means it's Hotline update season! (new releases falling and such, you get it)

The promise has been that we will only support the most recent 2 releases of macOS. Though I didn't adjust the OS version number in this build, the next build will. So anything less than macOS 26 will no longer be supported. This helps keep the project and app fresh and working on Apple's latest while also reducing the complexity of working on this project so it doesn't become a burden.

### New in b29:
- Server themes! Each server now takes on colors to make each server feel like a unique space. These colors are pulled from a server's banner image. You can disable themes in settings.
- New connection interface! I've taken a stab at rethinking the connection form in Hotline. Now you can just start typing a server name into the address field and it will show suggestions based on your bookmarks and any trackers you have added automatically. Recent servers appear under the address field.
- Liquid Glass! Some Liquid Glass effects are now used in the toolbar and a few other places.
- Full color toolbar: we're now generating more colors from server banners to make the toolbar even more themed.
- Instant server banners: we now cache server banners locally so you see it immediately upon signing in.
